POP CRAZE POS

This version is based on the original Product Service POS and adds a simple mode switch:
- Product Service: orange theme and the original product POS screens.
- Technical Service: blue theme and a separate technical-service form and service records.
- The top button switches between the two modes. In Technical Service mode it changes its label to Product Service so you can switch back.

To use:
1. Extract this ZIP file.
2. Upload the contents of the POP_CRAZE_POS folder to your GitHub repository, replacing the existing app files.
3. Open your GitHub Pages website and refresh it.

Data note: Product POS data is stored in this browser using localStorage. Technical service records are stored separately in this browser. GitHub Pages does not provide cloud database sync. Keep backups of product data using Settings / Backup. Technical service records currently have no export/backup feature, so avoid clearing browser/site data.
